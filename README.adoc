== About The Project

Public community hub for https://github.com/LinxPhotos[LinxPhotos] — photo portfolio hosting and tools for photographers.

This repository holds **GitHub Discussions** only (not product source). It is aimed at tech-savvy fans who want to talk shop, share setups, propose ideas, and help shape what we build.

== Usage

=== How to participate

1. Open the link:https://github.com/LinxPhotos/discussion/discussions[Discussions] tab.
2. Pick a category that matches your post.
3. Search first — someone may already have asked or shared the same thing.
4. Be concrete: product name, platform, version, and what you expected vs. what happened.

Issues and pull requests for individual products belong in those product repositories, not here.

=== Categories

[cols="1,3",options="header"]
|===
| Category | Use it for

| *Announcements*
| Official updates from maintainers

| *General*
| Open conversation about LinxPhotos, photography workflows, and related tooling

| *Ideas*
| Feature requests and product direction

| *Q&A*
| Questions and troubleshooting (community + maintainers)

| *Show and tell*
| Portfolios, layouts, pipelines, and cool things you built with our tools

| *Polls*
| Community votes when we need a clear preference
|===
